Pre-Installation

Before You Begin

The steps below assume you're using the Steam version of the game. Complete every step before moving on to Installation.

Setup Steps

  1. Perform a clean install of Cyberpunk 2077. Install it outside of Program Files.

  2. Install the Visual C++ Redistributables (All-in-One). Extract and run install_all.bat as administrator.

  3. Disable Steam auto-updates for Cyberpunk 2077.

    How to disable auto-updates
    1. Right-click Cyberpunk 2077 in your Steam Library → Properties
    2. Go to the Updates tab
    3. Set Automatic Updates to "Only update this game when I launch it"
    4. From now on, only launch through Mod Organizer 2

  4. Make sure all official DLC is installed.

  5. Install REDmod if you haven't already.

  6. Update your GPU drivers — NVIDIA App or AMD Adrenalin.

  7. Install the .NET Runtime (latest version).

  8. Install the DirectX End-User Runtime.

Before Moving On

Confirm that Steam shows both Cyberpunk 2077: REDmod and Cyberpunk 2077: Phantom Liberty as installed before continuing to the Installation page.

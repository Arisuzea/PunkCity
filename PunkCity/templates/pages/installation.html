Installing PunkCity

Choose the method that applies to you. Both paths end at the same place — pick whichever is available.

Availability

The gallery listing is now officially live, remember to tick Non-featured in the Wabbajack browse modlist section.

  1. Download Wabbajack and place it somewhere outside your Cyberpunk folder and outside Program Files.

    Example: D:\Wabbajack

  2. Launch Wabbajack. On the main screen, click Browse Modlists.

    Note

    Please make sure to tick Non-featured otherwise the list may not show up.

  3. Search for PunkCity in the gallery and click the download arrow to begin.

  4. Set your install paths:

    Installation: D:\Modlists\PunkCity
    Downloads: D:\Modlists\downloads

    Path Rules

    Both paths must be on the same drive as your Cyberpunk install, and not inside the game directory or Program Files.

  5. Click Install and let Wabbajack handle the rest. This will take a while depending on your connection speed.

  6. Once complete, open your install folder and launch ModOrganizer.exe.

  7. Confirm the active profile is set to PunkCity, then click Run.

When to use this?

Use this method if the Wabbajack gallery listing isn't live yet, or if you prefer to download the .wabbajack file manually from the Nexus page.

  1. Download Wabbajack and place it somewhere outside your Cyberpunk folder and outside Program Files.

    Example: D:\Wabbajack

  2. Go to the PunkCity Nexus Mods page and download the main file, it contains .wabbajack to install file manually. Save it anywhere convenient.

  3. Launch Wabbajack. Navigate to Browse Modlists, on the top right click Install from Disk.

  4. In the file picker, navigate to and select the PunkCity.wabbajack file you just downloaded.

  5. Set your install paths:

    Installation: D:\Modlists\PunkCity
    Downloads: D:\Modlists\downloads

    Path Rules

    Both paths must be on the same drive as your Cyberpunk install, and not inside the game directory or Program Files.

  6. Click Install and let Wabbajack handle the rest.

  7. Once complete, open your install folder and launch ModOrganizer.exe.

  8. Confirm the active profile is set to PunkCity, then click Run.
